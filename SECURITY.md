# Security Policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue or pull
request.

As of 2026-08-21, private vulnerability reporting is not enabled for this
repository. Use the private contact route listed on the [pumni GitHub
profile](https://github.com/pumni) and do not send sensitive details through a
public channel. If no private contact route is available there, ask the
repository owner to enable GitHub private vulnerability reporting before
sharing the report.

Once enabled, the intended route is [Report a
vulnerability](https://github.com/pumni/web-os/security/advisories/new).

Include the affected revision, a concise impact description, reproduction steps,
and any suggested mitigation. Please allow maintainers reasonable time to
investigate and coordinate disclosure before publishing details.

## Supported versions

Only the current `main` branch is actively maintained. Security fixes should
be verified against the exact revision where the issue is reported.
