# Implementation plans

This directory contains only implementation plans for current work. Active
plans are subordinate to repository source, security boundaries, CI, and the
applicable `AGENTS.md` files.

Completed plans are removed from the working tree after acceptance; Git history
is the archive. Do not create a permanent completed-plan directory.

There are currently no active implementation plans. Create a plan here only
for work that is in progress, and remove it after the work is accepted.
